Shrek 2 (2004) PC — Unified Patch

For the original 2004 PC game (KnowWonder / Activision, Unreal Engine 2). Not for the 2026 remaster: it won’t work with it.

Widescreen, modern resolutions, crash fixes, intro skip and the developers’ hidden menu for the 2004 PC game. One installer, every file verified, rollback included.

Download 1.6Source codeVersion 1.6 · Windows · .NET Framework 4

What it does

Widescreen

Up to 2560×1440 (720p, 768p, 900p, 1080p, 1152p, 1440p). Hor+ camera with a wider horizontal view. The HUD, menus and subtitles keep their 4:3 proportions, centred on the screen.

Window & VSync

Fullscreen or windowed mode, VSync on/off. New video settings revert automatically after 15 seconds unless you confirm them.

Movies

Bink movies keep their aspect ratio with side bars and use the 1024 versions where available. Fixes stripes, wrong colours and a decoder buffer overrun.

Crash fixes

Fixes the crash when switching VSync to “Off” (broken bool bytecode in SHGame.u), Alt+F4 doing nothing in fullscreen, settings tabs going off screen, and array bound errors.

Intro skip

No DreamWorks / Activision / KnowWonder logo movies: the game goes straight to the menu, and the storybook opens about 4× faster.

Developer menu

An optional checkbox binds F9 (developer mode) and F10 (Dev Menu): load any map, use bookmark teleports, pick the story state.

Installation

  1. Close the game.
  2. Download Shrek2VideoPatch-1.6.exe and run it.
  3. Select the game’s System folder and click Установить патч (Install patch; the installer window is in Russian). If you want F9/F10, tick Разблокировать меню разработчиков (Unlock developer menu) first.
  4. In the game, open Options → Video, choose a resolution, apply and confirm.

Восстановить оригинал (Restore original) puts back every original file from System\Shrek2VideoPatchBackup and removes the key bindings. Every file is checked by SHA-256 before and after patching. If a file is unknown, nothing is changed.

Built and tested on the Russian retail PC release. Other language versions will most likely be rejected without changes. No game files are included: the installer only contains binary diffs and applies them to your own copy.

Cut content found in the files

225 unused voiced lines

Recorded and listed in HpDialog.int, but nothing in the game plays them. 149 are combat barks from peasants, knights, bandits, elves and Mongo (an abandoned chatter system). 76 are story lines.

Fairy Godmother commercial

A TV spot for her potions (“limited edition”), plus a FGM drive-thru scene with Shrek and Donkey.

Lost tutorials and levels

Donkey’s HUD tutorial (health, coins, double jump), a giant pumpkin and Peter the Pumpkin Eater, and Puss talking about fire vents, lasers, the dwarves’ caves and Jack and Jill’s hill.

Book_StoryBook.unr

A map that nothing links to: the storybook, Shrek and 15 cameras. It looks like an early storybook prototype. Also 86 dialogue sounds with no text.

Debug tools

Dev Menu, a UWindows debug bar (F2), and cheats: FraserIsGod, AddCoins, AddPotions, FreeCam, GameSpeedUp…
